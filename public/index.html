📦 Descargar / Instalar

El juego necesita una clave API de Anthropic (gratuita en console.anthropic.com). Elige tu plataforma:

🌐 Web / Local (ya disponible)

Juega ahora mismo en el navegador. Para jugar en local en tu PC:

git clone https://github.com/lord-jorx/fluffy-train
cd fluffy-train
npm install
echo "ANTHROPIC_API_KEY=sk-ant-..." > .env
npm start

Abre http://localhost:3000

🖥️ Windows / Linux / Steam Deck

App de escritorio con Electron (no necesita navegador ni servidor separado):

npm install
# Windows (.exe):
npm run build:win

# Linux / Steam Deck (.AppImage):
npm run build:linux

El instalador aparece en dist/. En Steam Deck: añade el .AppImage como juego no-Steam.

🤖 Android

App nativa con Capacitor:

npm install
npx cap add android
npx cap sync
npx cap open android

Necesitas Android Studio. La app pedirá tu clave API al iniciarse.

🍎 iPhone / iPad

App nativa con Capacitor (requiere Mac + Xcode):

npm install
npx cap add ios
npx cap sync
npx cap open ios

La app pedirá tu clave API al iniciarse. Necesitas una cuenta de desarrollador Apple para instalar en dispositivo.

Sobre la clave API: Anthropic ofrece créditos gratuitos al registrarte. El juego usa el modelo Claude Opus 4.8 — una sesión de juego típica cuesta unos pocos céntimos.
